## Slide 2: The Visualization Gap in Coding Education

* **Visual Layout**: Large headline: **"Why Do Students Struggle with Coding?"**. Side-by-side graphic contrasting static blackboard/textbook explanations of memory arrays and pointers with complex local debuggers that beginners find overwhelming.
* **Slide Copy**:
  * **The Visual Gap**: Concepts like pointers referencing memory addresses, stack frames, and sorting indexes are taught statically.
  * **The Lab Bottleneck**: In a typical 2-hour lab of 60+ students, a single professor cannot trace code step-by-step for everyone.
  * **Logical Errors**: Students write code but lack the mental model to debug logical errors, leading to frustration and drop-out rates.
* **Speaker Script**:
  > "When students start coding, they struggle to visualize what happens inside memory. Pointers, linked lists, recursive stacks, and database joins are explained on static blackboards or slides. When students write code in labs, they can't visualize variables changing, leading to logical errors. With large lab cohorts, instructors can't offer 1-on-1 tracing guidance."

## Slide 6: The Student User Journey

* **Visual Layout**: Flow diagram showing Aarav's path: Monaco Editor $\rightarrow$ Step-by-Step Visualization $\rightarrow$ Variables Board tracking mutations $\rightarrow$ AI Tutor hints $\rightarrow$ XP points and digital certification.
* **Slide Copy**:
  * **Write Code**: Enter standard C, Python, or SQL code in Monaco.
  * **Trace State**: Run visual playback (Play, Pause, Speed control).
  * **Analyze Scope**: Variables board updates values dynamically.
  * **Engage AI**: Slide-out tutor chatbot answers conceptual queries.
* **Speaker Script**:
  > "Here is the student's journey: Aarav types his code in our Monaco editor. Instead of running it blindly, he hits 'Visualize' to trace the states step-by-step. He sees variables mutating in the sidebar. When he is confused, he chats with the AI Tutor, resolves the bug himself, earns XP, and maintains his coding streak."
